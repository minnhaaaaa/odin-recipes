The Odin Recipes

This project is a recipe website, made to practice all the HTML and CSS knowledge that I have gained through the Foundations Course of the Odin Project. The website contains a main page that links to three different recipes. It contains CSS styling which implements margin,padding and border aspects.

The skills that I have demonstrated during this project are:
-Handle HTML lists,links and images 
-Create and navigate through proper file structures using VSCode and Linux command terminal
-Understand and write git commits through terminal
-Handle CSS styling for different HTML pages and integrate learnings regarding the box model
